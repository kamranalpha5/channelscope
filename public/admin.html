Tokens & plans

Every logged-in user gets 100 free tokens per day (refreshes daily, never accumulates). Paid plans: Starter $2/mo = 1,500 tokens/mo, Pro $5/mo = 5,000 tokens/mo. Costs: map Depth 1 = 50, Depth 2 = 100, Depth 4 = 200 tokens; Trending run = 50. Cached views cost 0.

Stripe setup: set STRIPE_SECRET_KEY, STRIPE_PUBLISHABLE_KEY, STRIPE_WEBHOOK_SECRET, STRIPE_PRICE_1500 and STRIPE_PRICE_5000 as env vars (Render dashboard → Environment). Create two recurring monthly prices in the Stripe dashboard (Starter $2, Pro $5) and paste their price IDs. Webhook endpoint: https://<your-domain>/api/billing/webhook — listen for checkout.session.completed, invoice.paid, customer.subscription.deleted and customer.subscription.updated. Until the keys are set, the Pricing page shows “Payments coming soon”.
